Windows

The Windows build is a first-class agent host, not a zip of the macOS tree. Adding a project on Windows runs a doctor: long paths, Git Bash, Node 22, and whether the repo sits across a WSL boundary.

The Windows build is a first-class agent host, not a zip of the macOS tree. Adding a project on Windows runs a doctor: long paths, Git Bash, Node 22, and whether the repo sits across a WSL boundary. Failed checks are advisory (they do not block add), but they name the fix. Agent CLIs stay attached to the app so Stop stops them, and a sandbox badge shows how the run is isolated.
