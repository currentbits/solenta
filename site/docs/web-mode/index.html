Phones and browsers

Solenta Web serves the whole app to a browser, so you can check on runs from your phone or another device. It runs on the computer that has your projects and agents. Everything is set up in Settings > Connections > Let other devices in:

  1. Turn on Serve Solenta Web. It listens on 127.0.0.1:4620, which only this computer can reach.
  2. To reach it from another device, either turn on Allow devices on my network (plain HTTP on your LAN) or, with Tailscale installed, press Expose over Tailscale (HTTPS) to reach it from anywhere on your tailnet.
  3. Under Devices, name the device, pick its access and press Add device. Scan the QR code with the device's camera or open the link on it. The token is shown once and the browser remembers it.

Access is per device: Read only, Steer threads (the default) or Full access, plus grants for files, git, the terminal (watch or type), preview control and settings. Solenta checks every request against them on the host. Steer threads can approve the agent's tool requests. To change a device's access, revoke it and pair again. Revoking signs the device out at once and its browser asks for a new token.

If the connection drops, the page says so and reconnects on its own. A message you send in the meantime waits and goes out once the connection is back.

You can also start Solenta Web from a terminal. It prints the address, the token, a sign-in link and a QR code: 

# macOS
/Applications/Solenta.app/Contents/MacOS/Solenta --serve-web
# Linux (the unpacked tarball)
~/solenta/solenta --serve-web --serve-host 0.0.0.0   # LAN, plain HTTP

If Solenta is already open, this turns Solenta Web on in that app and prints its token. There is no TLS on the LAN bind; use Tailscale for HTTPS.
