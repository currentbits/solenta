Review itinerary

Opening an agent's diff should not mean reading files top to bottom. The review itinerary builds an ordered, risk-ranked plan from the working-tree diff: CI and config first (a hard stop if those moved), then a scan for duplicated utilities, the critical path, tests, and the rest, chunked by functional area, never alphabetically.
