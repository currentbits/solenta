# App.tsx split (issue #1447, round 5, pass N)

`src/App.tsx` is 2,732 lines on origin/main (6763da60); the `App` component is
lines 204–2732. It destructures ~220 values from `useCoder()` and wires them
into the three memo'd panes (Sidebar, ThreadView, AgentsPanel), the report
views and the modals.

Goal: move contiguous hook blocks into custom hooks under `src/app/` without
changing behaviour. Rules: a block moves only if it is contiguous, the hook is
called exactly where the block was, bodies and deps are verbatim, and every
`useCallback` keeps the same deps so memo'd panes still skip renders. State
declarations and refs stay where they are in `App`; hooks receive setters
(stable) and refs (stable) as arguments.

Presentational candidates (JSX only, no hooks): `NarrowBar` (narrow toolbar + scrims), `SidebarRail`, `AgentsRail`, the report-view switch, the toast stack. These add a component boundary but no state, so the DOM is unchanged; they are lower value than the hooks and come after them.

## What is not safe and why

- **View/inspector core (465–660).** State declarations, render-time ref
  assignments (`viewRef.current = view`, `inspectorProjectIdRef.current` at
  1372) and callbacks that read those refs are interleaved. The ref written at
  1372 is assigned *after* `rememberInspectorTab` is created but read from it
  later; moving either side changes when the write happens relative to other
  render code. Leave it until the inspector derivation is rewritten
  deliberately.
- **Drawer effects 4 and 10.** They bracket effects 5–9. A `useDrawers` hook
  would have to be called twice or would reorder effects. Leave them inline.
- **Early return.** `if (buildMismatch) return …` sits after every hook, so
  all hook calls stay unconditional; nothing may move below it.

Each step is one commit, verified by typecheck, `vite build`, the renderer
suite TAP count and a pure-move diff check. At the end an effect-order
script compares main against the branch with each hook expanded inline.
