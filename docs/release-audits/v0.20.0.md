# Solenta 0.20.0 release coverage audit

Audited 2026-09-11 against the immutable release tag. The announcement also covers 0.19.0, which had not been announced separately.

## Boundary and why earlier notes missed the work

- 0.20.0: `v0.19.0` (`28fd1f8f`) through `v0.20.0` (`6ea67a38`).
- 0.19.0: `v0.18.1` (`ca95b203`) through `v0.19.0` (`28fd1f8f`).
- PR #1265 (`f6c9323a`) has a narrow writer-lock title but changes 284 files, adding 63,782 lines and removing 2,508. Its actual patch includes many independent features and fixes. PR titles and closed Planboard labels were insufficient evidence.
- Reviewed the complete changed-file inventory, added regression cases, issue references, implementation and UI wiring. Checked PR merge commits against the release tags, including direct commits and merges. Grouped related fixes below without presenting every test or refactor as a product feature.
- The GitHub release still had an autogenerated PR list when this audit started; the correction replaces it with this curated inventory.
- Best of N isolation PR #1272 merged into a feature branch, not this release. Existing Best of N is not evidence that the isolation fix shipped.
- Astra support was already announced in the 0.18.1 changelog. The 0.20.0 changes are model switching, steering, approvals and other Codex integration fixes.
- Cache/export budgets are estimates of retained payload, not total JavaScript heap or app RSS. No unsupported percentage speedup or RAM reduction is claimed.
