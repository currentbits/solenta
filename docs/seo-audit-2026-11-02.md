## Reproduction and maintenance

The site remains static; generated files are committed. No new npm dependency
is needed to serve it or run its regression tests.

```sh
# Requires cwebp from libwebp; leaves the canonical PNGs untouched.
node scripts/build-site-images.js
# Refresh llms-full.txt and dated sitemap after page edits, before committing.
npm run build:site
node --test electron/test/site-*.test.js
docker build -t solenta-seo-1837 site
docker run --rm -d --name solenta-seo-1837 -p 127.0.0.1:8187:80 solenta-seo-1837
node scripts/verify-site-seo.js http://localhost:8187
docker stop solenta-seo-1837
# After an approved deployment:
node scripts/verify-site-seo.js https://solenta.app
```

The sitemap uses the most recent file commit date, or today's UTC date when the
page has uncommitted edits. Regenerate if committing those edits on a later day.
The version test intentionally fails if a new release heading is added without
updating SoftwareApplication.softwareVersion.

Geist fallback computation used fontkit 2.0.4 and the
[Next.js local-font calculator](https://github.com/vercel/next.js/blob/canary/packages/font/src/local/get-fallback-metrics-from-font-file.ts).
For the bundled file: unitsPerEm=1000, ascent=920, descent=-220, lineGap=100,
weighted average advance=489.1162790697674. The calculator's Arial average is
934.5116279069767 / 2048. Size adjustment is their normalized width ratio;
ascent/descent/line gap are divided by that ratio, yielding 107.19%, 85.83%,
20.52%, 9.33%. Only Arial is used for this fallback because these metrics were
calculated against Arial, not three different local fonts.

Screenshots measured in Chromium at 412 and 1440 px: hero 362/1078 px,
workflow 362/761 px, kanban and automations 362/566 px. The sizes attributes
follow the existing 900 px single-column breakpoint and 1200 px wrapper cap.
The four PNGs total 544,192 bytes; the four 800 px WebPs total 57,258 bytes,
and the four 1680 px WebPs total 184,140 bytes. These are file sizes, not a
promise about transfer size, traffic or field performance.
